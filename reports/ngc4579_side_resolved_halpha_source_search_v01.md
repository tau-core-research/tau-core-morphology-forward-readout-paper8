# NGC4579 side-resolved Halpha source search v01

Status: `SIDE_RESOLVED_HALPHA_NUMERIC_PRODUCT_NOT_RECOVERED`

The archived FaNTOmM/SINGS author index and NGC4579 page were recovered. The
numeric `ngc4579.dat` curve is source-averaged and retains side disagreement
only through `side_error` and `final_error`. The object page links one composite
PNG but no FITS velocity field or data cube; the PNG was not preserved at the
tested archive path.

The full published Figure C2 was subsequently recovered, but it also contains
only one averaged curve. Public archive searches did not recover the original
FaNTOmM FITS velocity field or cube; IRSA SINGS FITS products are not this
Fabry-Perot kinematic product. The Virgo atlas additionally reports larger
velocity dispersion in the receding half, reinforcing side asymmetry as a
conventional nuisance.

The existing replay therefore tests the common/even velocity-amplitude sector.
NGC4579 is `BLOCKED_SOURCE_PRODUCT` for the orientation-odd observer-time
endpoint until the original velocity product or another side-resolved source
is acquired.
